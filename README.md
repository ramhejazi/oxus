# oxus (WIP)

oxus is a download manager and a wrapper for yt-dlp.

I have been using oxus for about 5 years now, but recently I wanted to add more features to it, including support for HTTP and torrent downloads, along with more flexible configuration options. 

I have decided to start a new repo and open-source an application I've been using on a daily basis for the past couple of years.

## Roadmap
To keep this repository clean and introduce features gradually, I will be adding modules one by one alongside unit tests. Eventually, all core daemon components will be migrated here.
